1Quem somos

O SoloForte é um aplicativo móvel voltado para agrônomos e gestores agrícolas, desenvolvido e operado pela SoloForte Tecnologia Agrícola, com sede no Brasil.

Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos os seus dados pessoais ao utilizar o aplicativo SoloForte (iOS).

🌱 Dúvidas sobre privacidade? Entre em contato: privacidade@soloforte.com

2Dados coletados

Coletamos apenas os dados necessários para o funcionamento do aplicativo:

  • Dados de conta: nome, endereço de e-mail, senha (hash — nunca em texto puro).
  • Dados agrícolas: geometria de talhões (polígonos), ocorrências de campo, relatórios de visita, registros de NDVI e dados de safra inseridos por você.
  • Dados de localização: coordenadas GPS usadas exclusivamente para georreferenciamento de talhões e ocorrências dentro do app. Não compartilhamos sua localização com terceiros.
  • Dados de uso: logs de autenticação (Supabase Auth) para segurança da conta. Não usamos analytics comportamentais de terceiros.
  • Dados de pagamento: processados diretamente pelo Mercado Pago. O SoloForte não armazena dados de cartão de crédito.

3Como usamos seus dados

  • Autenticação e segurança da sua conta.
  • Sincronização dos seus dados agrícolas entre dispositivos.
  • Geração de relatórios técnicos de visita.
  • Processamento de pagamentos de planos (Bronze, Prata, Ouro).
  • Envio de e-mails transacionais (recuperação de senha, confirmação de conta).
ℹ️ Não usamos seus dados para fins publicitários, nem os vendemos a terceiros.

4Armazenamento e segurança

Seus dados são armazenados localmente no dispositivo (SQLite — offline-first) e sincronizados com servidores seguros hospedados pela Supabase (infraestrutura AWS, região América do Sul).

  • Comunicação criptografada via TLS 1.2+ em trânsito.
  • Row Level Security (RLS) — cada usuário acessa exclusivamente os próprios dados.
  • Senhas armazenadas como hash — nunca em texto puro.
⚠️ O SoloForte opera em modelo offline-first: dados criados sem conexão são salvos localmente e sincronizados quando a rede estiver disponível.

5Compartilhamento de dados

Seus dados não são vendidos. Compartilhamos apenas com parceiros estritamente necessários para o funcionamento do serviço:

Supabase Backend, autenticação e armazenamento seguro na nuvem.
Mercado Pago Processamento de pagamentos. Nenhum dado de cartão é armazenado pelo SoloForte.
Apple Distribuição via App Store. Métricas agregadas de crash, mediante seu consentimento no iOS.

6Retenção de dados

Mantemos seus dados enquanto sua conta estiver ativa. Após a exclusão da conta, seus dados pessoais são removidos em até 30 dias, exceto registros exigidos por obrigações legais — como dados fiscais de pagamentos, retidos por 5 anos conforme a legislação brasileira.

7Seus direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

Acessar seus dados pessoais
Corrigir dados incorretos ou desatualizados
Solicitar portabilidade dos seus dados
Solicitar a exclusão dos seus dados
Revogar o consentimento a qualquer momento

Para exercer esses direitos, acesse Configurações → Minha Conta → Excluir conta dentro do app, ou envie uma solicitação para privacidade@soloforte.com.

8Exclusão de conta

Você pode excluir sua conta diretamente no app em Configurações → Minha Conta → Excluir conta. A exclusão é irreversível e remove todos os seus dados pessoais dos nossos servidores dentro de 30 dias.

Dados armazenados localmente no dispositivo devem ser removidos manualmente desinstalando o app.

9Menores de idade

O SoloForte é destinado exclusivamente a profissionais de agronomia e adultos (maiores de 18 anos). Não coletamos dados de menores de idade intencionalmente. Caso identifiquemos tal situação, os dados serão removidos imediatamente.

10Alterações nesta política

Podemos atualizar esta Política periodicamente. Notificaremos mudanças significativas via e-mail cadastrado ou notificação no app. O uso continuado do aplicativo após as alterações implica aceite dos novos termos.
